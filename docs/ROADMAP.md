# Roadmap

Không đặt hạn chót. Mỗi milestone kết thúc bằng một bản chơi được; xong cái trước mới sang cái sau.

## M0 — Khởi tạo dự án

- [x] Chọn công nghệ: Phaser + TypeScript + Vite
- [x] Dựng skeleton, màn hình mẫu chạm để tích linh khí
- [x] Game Design Doc bản nháp, roadmap, quy ước làm việc
- [ ] Đẩy code lên GitHub
- [ ] Bật GitHub Pages để có link chơi trên điện thoại và máy tính

## M1 — Tu luyện và đột phá

- [ ] Linh khí tăng theo thời gian, kể cả lúc tắt game
- [ ] Bảng chỉ số nhân vật
- [ ] Đột phá cảnh giới đầu tiên, có hiệu ứng
- [ ] Lưu và tải tiến trình

## M2 — Chiến đấu theo lượt

- [ ] Màn hình trận đấu một đấu một
- [ ] Đánh thường, kỹ năng, phòng thủ
- [ ] 2-3 loại kẻ địch
- [ ] Phần thưởng sau trận

Hết M2 là có bản MVP: tu luyện → chiến đấu → đột phá.

## M3 — Khám phá

- [ ] Bản đồ thành phố dạng các điểm nối nhau
- [ ] Sự kiện tại mỗi điểm
- [ ] Túi đồ và vật phẩm

## M4 — Giải đố

- [ ] Chọn loại câu đố
- [ ] Bí cảnh đầu tiên mở bằng câu đố
- [ ] Kiếp nạn khi đột phá

## M5 — Ba con đường và nội dung

- [ ] Tu tiên, dị năng, thể tu với kỹ năng riêng
- [ ] Thêm cảnh giới, khu vực, kẻ địch
- [ ] Cân bằng chỉ số

## M6 — Hình ảnh và âm thanh

- [ ] Thay hình tạm bằng asset chính thức
- [ ] Hiệu ứng, chuyển cảnh
- [ ] Nhạc nền và âm thanh

## M7 — Hai người chung máy chủ

- [ ] Chọn dịch vụ lưu trữ trực tuyến
- [ ] Tài khoản và lưu tiến trình trên máy chủ
- [ ] Tương tác giữa hai người chơi

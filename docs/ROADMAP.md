# Roadmap

Không đặt hạn chót. Mỗi milestone kết thúc bằng một bản chơi được; xong cái trước mới sang cái sau.

## M0 — Khởi tạo dự án

- [x] Chọn công nghệ: Phaser + TypeScript + Vite
- [x] Dựng skeleton, màn hình mẫu chạm để tích linh khí
- [x] Game Design Doc bản nháp, roadmap, quy ước làm việc
- [x] Đẩy code lên GitHub
- [x] Bật GitHub Pages để có link chơi trên điện thoại và máy tính

## M1 — Tu luyện và đột phá

- [x] Tạo nhân vật: chọn nhánh chính, quay linh căn, dị năng bản mệnh
- [x] Bảng sáu chỉ số
- [x] Tu luyện nhánh chính qua 5 bậc Nhân giới, mỗi bậc 3 giai đoạn
- [x] Đột phá có hiệu ứng, cộng chỉ số theo nhánh
- [x] Lưu tiến trình; tu tiên tích linh khí cả khi tắt game
- [ ] Chơi thử và chỉnh con số (tốc độ, năng lượng cần)

## M2 — Bản đồ lịch luyện

- [x] Hai tầng chơi: bản thể (thời gian thật) và lịch luyện kiếp (lịch trong game)
- [x] Bản đồ Lạc Thành với 10 địa danh, kéo để xem
- [x] Thế giới rộng gấp 10: năm vùng đất, 36 địa danh, bến thuyền và đường biển, chế độ toàn cảnh
- [x] Kiếp bắt đầu là Phàm Nhân, xuất thân ngẫu nhiên, đột phá có thể thất bại
- [x] Sự kiện tách ra file riêng kèm hướng dẫn viết
- [x] Thêm Đông Sơn Châu, Xích Diệm Châu và hai đảo lẻ (51 địa danh)
- [x] Phóng to thu nhỏ bằng hai ngón tay và con lăn chuột
- [x] Mức nguy hiểm từng nơi, nơi sinh ngẫu nhiên
- [x] Đột phá tốn linh thạch, làm thuê kiếm linh thạch, càng lên cao càng khó
- [x] Nhân vật nam và nữ mặc định (hình tạm)
- [x] Thiên Nam Đại Lục: năm quốc gia liền nhau, 12 thành thị, quan ải, cảng ra đảo (64 địa danh)
- [ ] Thay hình nhân vật bằng ảnh do công cụ AI vẽ (mô tả ở docs/NHAN-VAT.md)
- [x] Di chuyển theo đường nối, lịch trôi theo số ngày đi
- [x] Bế quan theo tháng, linh khí khác nhau từng nơi
- [x] Tuổi thọ, kết thúc kiếp, nhận điểm luân hồi
- [x] Sự kiện dạng văn bản có lựa chọn (11 sự kiện đầu tiên)
- [x] Bản đồ vẽ kiểu bản đồ thế giới, có chuyển động
- [x] Cảm ngộ nối kiếp với bản thể
- [ ] Nhận thêm sự kiện từ người viết, sự kiện nối tiếp nhau
- [ ] Việc thường nhật ở từng địa điểm
- [ ] Màu viền báo mức nguy hiểm

## M3 — Chiến đấu theo lượt

- [ ] Màn hình trận đấu một đấu một
- [ ] Đánh thường, kỹ năng, phòng thủ
- [ ] Dị thú ở các vùng dị thú; gặp dị thú và người tu luyện khác trên đường
- [ ] Cân lại độ khó (tỉ lệ bị tập kích, bỏ mạng) sau khi có chiến đấu
- [ ] Phần thưởng sau trận: linh thạch, nguyên liệu

## M4 — Điểm luân hồi, linh thạch, giải đố

- [ ] Cửa hàng điểm luân hồi ở thế giới chính
- [ ] Xuất thân và lợi thế đầu kiếp, chọn nơi sinh
- [ ] Phường thị mua bán bằng linh thạch
- [ ] Bí cảnh Phong Nha với câu đố đầu tiên

## M5 — Nhánh phụ, dị năng, luân hồi

- [ ] Tu nhánh phụ (tốc độ một nửa)
- [ ] Dị hạch, thức tỉnh và nâng phẩm chất dị năng (tối đa 5)
- [ ] Nhiệm vụ chính tuyến và cốt truyện cho bản thể
- [ ] Linh giới, Tiên giới, thêm khu vực và kẻ địch
- [ ] Cân bằng chỉ số

## M6 — Hình ảnh và âm thanh

- [ ] Thay hình tạm bằng asset chính thức
- [ ] Hiệu ứng, chuyển cảnh
- [ ] Nhạc nền và âm thanh

## M7 — Hai người chung máy chủ

- [ ] Chọn dịch vụ lưu trữ trực tuyến
- [ ] Tài khoản và lưu tiến trình trên máy chủ
- [ ] Tương tác giữa hai người chơi
